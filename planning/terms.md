# Terminology ledger
<!-- SUMMARY: term sheet for the rebuilt category paper (ELL, entirely new submission): which terms ELL's reader owns, which the paper must gloss at first use, and which it avoids; replaces the 18 Sep ledger written for a CGEL-aware reader · status: active · updated: 2026-10-24 -->

**Reader assumed (from 24 Oct):** an English grammarian reading *English Language and Linguistics* who does **not** work in *CGEL*'s framework. Every *CGEL*-specific term is earned, not free.

The 18 Sep ledger assumed "a general theoretical-linguistics audience that knows *CGEL*". Its four rows are carried over below where they still apply.

## Free (ELL's reader owns these)

| Term | Note |
|---|---|
| noun, pronoun, proper noun, common noun | Ordinary grammatical sense. |
| determiner | **Only as the name of a function** (see "determiner" under Earned for the category). Many ELL readers use it for the words; the paper's first use must fix the function sense. |
| noun phrase (NP), head, dependent, modifier, complement | Ordinary sense. "Dependent" in the paper's narrower sense (a determinative's use with a nominal target) is earned. |
| partitive, genitive, plural, number agreement | Ordinary sense. |
| quantifier | Free across categories; gloss once that it names a meaning, not a category ("expressions specifying quantity", as in the 18 Sep ledger). |
| corpus, COCA, NOW, iWeb | Name and cite at first mention. |
| lexical category, subcategory | The paper's general terms for what it classifies. |

## Earned (gloss at first prose use; the abstract may use them before the gloss)

| Term | Gloss / where |
|---|---|
| determinative | The category: *the*, *a*, *this*, *some*, *every*, *few* and the rest, whatever their function. Gloss with the category/function distinction, on page one. |
| determiner (category sense) | Not used. If a source uses it for the category, quote it and say so. |
| *CGEL* | *The Cambridge Grammar of the English Language* (Huddleston & Pullum 2002); say on page one which of its analyses the paper keeps and which it revises. |
| nominal (Nom) | The unit between noun and NP (*old man* in *the old man*); needed only if the trees use it. |
| fused head | Only if the paper refers to *CGEL*'s analysis of *take some*; one sentence, with a pointer to the companion fusion paper. |
| secondary use | The paper's notion for proper nouns, pronouns, and determinatives used like common nouns (*the real you*, *a nobody*); define with examples at first use. |
| number transparency | Define with an example pair at first use (*a lot of students are*). |
| profile | The 18 Sep ledger's gloss: "the functions, dependents, forms, and meanings a category's members show". Use sparingly, and always glossed. |
| coordinate / nested | The paper's two structures for Noun's subcategories: determinative beside pronoun (coordinate) or inside it (nested, Hudson). Define on page one with a two-line diagram. |
| projection | *CGEL*'s sense (the phrase a word heads); gloss in apposition, or avoid. |

## Avoid

| Term | Use instead |
|---|---|
| word class, word-class, class (noun or verb), subclass | lexical category, subcategory, set, kind; "part of speech" only when reporting a source's term. Quotations keep their wording (Hudson: "no word class Determiner"). |
| predeterminer (bare) | predeterminer modifier (a function). |
| mother, daughter, sister (trees) | parent, child, sibling, except in quotations. |
| DP (Abney's sense) unglossed | Name the DP hypothesis as such; *CGEL*'s "determinative phrase" only if needed, glossed as not Abney's. The ELL triage suggests avoiding "DP" altogether. |
| HPC vocabulary: homeostatic, cluster, sub-cluster, projectibility, stabilizer, mechanism | Not used (HPC kept out of this paper; DECISIONS). Say what the evidence shows in distributional terms. |
| prototype, prototypical, centrality | Not used (the paper's criterion is categorical; the triage drops prototype vocabulary). |
| deitality | Not used (the definiteness paper's term). |
| finite / non-finite | tensed / non-tensed, if needed. |
| mass | non-count. |
